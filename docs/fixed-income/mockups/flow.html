Inbound RFQ · RFS · IOI → price → quote → receive & execute orders. One engine, three doors.

Client / counterparty celnet engine — event processor · pricing · best-ex Dealer / trader Execution · venues · book feedback loop

One engine, three doors. Whether the request arrives as an RFQ, an RFS stream subscription, or an IOI, it lands on the same edge → the central event processor prices it off one immutable curve snapshot → best-execution scans external venues and the internal book → if it's inside policy the price is auto-quoted, otherwise the dealer reviews skew/size and approves, counters or passes. The client's order is then captured, internalised against our axe/book where it improves the level (or routed to a venue), filled, and booked — with positions feeding risk straight back into the next re-mark.
