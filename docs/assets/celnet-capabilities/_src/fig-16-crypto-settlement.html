Linear · USD(T)-margined
Premium and payoff in the quote currency — the standard, exchange-quoted contract. Exactly generalized-BSM: the leaf assembles the funding carry and calls the shared agnostic engine. Zero new payoff math.
payoff = max( φ(ST − K), 0 )  [quote ccy]

Inverse · coin-marginedthe crux
Premium and payoff denominated in the base coin — the classic coin-settled contract. The 1/ST factor makes the payoff a non-linear function of the terminal price: a real convexity / measure subtlety, the single most likely place to ship a silent mis-price.
payoff = max( φ(ST − K), 0 ) / ST  [coins]
Vcoin = (φ/S₀)·e−b·t·( N(φd₁) − (K/F)·N(φd₂) )

Coin-measure Greeks
A coin-margined desk hedges in coins, so the inverse strip's price is in coins (USD-equivalent a derived field) and delta · gamma · vega are the coin-measure sensitivities — documented, never silently the USD ones.

Derivation by numeraire change (USD risk-neutral → coin / share measure): the 1/ST weight becomes a drift shift. The convexity term Cov(1/ST, payoff) is non-zero and material — a naive Vlin/S₀ is wrong.
