Click-to-Trade — from a streamed price to a confirmed fill, on the same channel
Server mints a tradable token
On the live two-way, the server issues an unguessable keyed-MAC token — sell-at-bid / buy-at-offer — cryptographically bound to that exact line and price. It cannot be forged or replayed onto another quote.

Execute — within the validity window
The client returns the token to deal. Last-look validity bounds the lifetime of the price; execution is idempotent, so a retried request can never double-fill.
