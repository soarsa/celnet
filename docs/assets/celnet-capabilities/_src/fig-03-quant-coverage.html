Validated against independent oracles — frozen golden tables & ~26 parity rows
Analytic / PDE / golden classes are gated to machine precision against an independent open-source reference library — frozen QuantLib golden tables for vanilla, digital, barrier, double-barrier, touch and Heston. Structured, MC, American/Bermudan, basket and LSV products are validated against closed-form limits, finite-difference, hand-pinned published constants and a rigorous Monte-Carlo standard error — never asserted plausibility. ~26 capability rows are gated vs independent oracles across a large multi-crate Rust workspace — depth and validation rigor SynOption does not match.
