Three deployment modes · one seam
Adapter swaps on the market-data / price-sink / order-exec seam traits move Celnet between StandaloneHybridCelerIntegrated — reversible swaps, never a rewrite. The Standalone adapters are built and fully tested; CelerIntegrated is the estate-native binding — the Celnet-side seam traits and FIX engine are built, and the live JVM/WebSocket distributor wiring lands through Celnet's implementation program behind the same seams. A conflating egress governor, a resilient market-data subscriber, vendor-feed normalisation and an intra-fleet partition map carry node-local speed into horizontal scale-out and fan-out to many counterparties. The same seam ingests external products and feeds.
Celnet is the FX-options pricing system-of-record in the Celer trade lifecycle — pricing, Greeks and the surface flow into the price path; option risk flows into the risk and position path.
The surrounding celertech-* estate components are the integration map: the Celer integration is built and seamed via the DeployMode market-data / price-sink / order-exec adapter traits, with the Standalone path built and tested. The full live JVM Celer estate lifecycle (distributor sidecar handshake, FX_OPTION mailbox calibration, inferred hops, tenant overlays, live quote-feed entitlement) lands through Celnet's implementation program on the carry-generalized engine, binding into the running estate.
