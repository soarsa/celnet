2. Architectural Critique & Implemented Hardening

1. Exotic Derivatives Lock-in

Critique: Exotic pricing arms previously bypassed the plugin registry entirely, forcing static dispatch to compiled-in engines.

Solution: Added ExoticHostModel, NativeExoticModel, and ExoticPluginModelEngine in celnet-server. Exotics now consult the active exotic plugin model with automatic fallback to native engines.

2. In-Place Runtime Replacement

Critique: Registry rejected duplicate IDs with InvalidInput("duplicate model id"), preventing online recalibration updates without service restarts.

Solution: Implemented replace_or_insert_native, replace_or_insert_native_rates, and replace_or_insert_native_exotic preserving stable discovery order.

3. Dynamic Model Selection

Critique: Model resolution was a naive scan picking the first model at index 0, blocking users from activating newer models.

Solution: Added explicit active model IDs: set_active_pricing_model, set_active_rates_model, and set_active_exotic_model with automatic fallback.

4. Algorithmic Strategy Pluggability

Critique: Algo orders were restricted to closed protobuf enums (TWAP, Optimal Liquidation) without user-defined strategy hooks.

Solution: Introduced StrategyRegistry, AlgoStrategyType::Custom, and AlgoParentOrder::step_strategy for dynamic slicing and TCA.

4. Verified Invariants & Code Blueprints

A. Dynamic Strategy Stepping in celnet-algo

let mut order = AlgoParentOrder::new_pluggable("ORD-101", "EURUSD", 1_000_000.0, 1.0850)?;
let mut strategy = registry.create_strategy("ADAPTIVE_SPREAD_SNIPER")?;
let book = MarketBookSnapshot::new(1.0850, 500_000.0, 1.0852, 400_000.0);

// Dynamic step calculation based on order book state
let slice = order.step_strategy(&mut *strategy, &book, 0.0, 300.0, 0.10)?;
order.record_fill(0, slice.unwrap().target_quantity, 1.0851)?;

B. In-Place Hot-Swapping of Models in celnet-plugin-host

let mut registry = ModelRegistry::new();
let model_id = registry.register_native(ProprietaryPricer::new(calib_v1))?;
registry.set_active_pricing_model(model_id)?;

// Online recalibration without stopping the server:
registry.replace_or_insert_native(ProprietaryPricer::new(calib_v2))?;
assert_eq!(registry.active_pricing_model_id(), Some(model_id));
