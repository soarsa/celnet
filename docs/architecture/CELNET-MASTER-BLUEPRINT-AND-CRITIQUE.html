Complete rejection of unsafe memory blocks. By leveraging strict CPU core pinning, cache-padded 64-byte alignment, borrow-based zero-copy views, and seqlock synchronization, CelNet achieves single-digit microsecond tick-to-trade without compromising memory safety.

Unifies Foreign Exchange (FX), Fixed Income & Cash Bonds (FI), Equities, Commodities, and Digital Assets under a single generalized cost-of-carry analytical framework. All pricing algorithms achieve exact IEEE 754 bit-identical parity against benchmark oracles.

P-03

Hardware Symbiosis & Lock-Free IPC

Direct wire-to-struct projection via Simple Binary Encoding (celnet-sbe), POSIX shared memory ring buffers (celnet-shm), and WebGPU compute pipelines (celnet-gpu) for 100,000+ path exotic Monte Carlo simulations.

P-04

Dual-Tier Configurable Consistency (ADR-0015)

Raft is wired everywhere but forced nowhere. Ultra-low latency market-maker books run on single-node fsync memory journals (<1 μs), while sovereign bank books and balance sheets replicate synchronously across Raft consensus quorums.

P-05

Institutional Regulatory Conformance

Native, zero-loss interoperability with ISDA Common Domain Model (CDM 2026), FIX Protocol (4.4 & 5.0 SP2), BCBS 239 risk data aggregation principles, Basel FRTB sensitivities (MAR21), and ISDA SIMM 2.6+ margin rules.

P-06

Extensibility via Metered Wasm Sandboxing

Institutional quants hot-deploy proprietary algorithmic pricing models compiled to WebAssembly. The in-process pure-Rust host (celnet-plugin-host) enforces deterministic fuel metering, preventing runaway loops or crashes from impacting adjacent pricing streams.

/// Converts an internal CelNet execution into a canonical ISDA CDM 2026 lifecycle event.
pub fn execution_to_cdm_event(
    exec: &Execution,
    issuer_lei: &str,
    client_id: &str,
) -> Result<CdmLifecycleEvent, String> {
    let trade_id = format!("TRD-CELNET-{}", exec.execution_id);
    let cdm_trade_id = CdmTradeIdentifier::new(issuer_lei, trade_id)
        .with_uti(format!("UTI-2026-{:012}", exec.execution_id));

    let parties = vec![
        CdmParty::new(issuer_lei, CdmPartyRole::ExecutingEntity)
            .with_name("Celnet Execution Venue"),
        CdmParty::new(client_id, CdmPartyRole::Counterparty)
            .with_name(format!("Client Account {client_id}")),
    ];

    // Canonical ISO-4217 settlement currency and product terms resolution...
    let product = CdmProduct {
        underlying,
        notional,
        notional_ccy,
        effective_date,
        termination_date,
        payout,
    };
    product.validate()?;

    let event_id = format!("EVT-{}-{:08}", epoch_nanos, exec.execution_id);
    Ok(CdmLifecycleEvent::new_execution(event_id, epoch_nanos, cdm_trade_id, product, parties))
}

05 Cross-Asset FIX 5.0 SP2 Quote & RFQ Engine

HIGH-FREQUENCY PROTOCOL

The native CelNet FIX engine (crates/celnet-fix) has been extended beyond FX and fixed-income to support institutional Equities (Product=7), Commodities (Product=2), and Digital Assets (Product=12) conforming to FIX 5.0 SP2 and FIX Latest. 

/// Price an inbound cross-asset option RFQ (Equities Product=7, Commodities Product=2, Digital Assets Product=12).
fn cross_asset_line(frame: &FrameCursor<'_>) -> Result<PricedLine, ()> {
    let rfq = dialect_cross_asset::decode_cross_asset_rfq(frame).map_err(|_| ())?;
    if rfq.is_american { return Err(()); }

    let spot = rfq.strike;
    let (fair_price, half_spread) = match rfq.product_kind {
        CrossAssetProductKind::Equity => {
            let inputs = EquityInputs::dividend_paying(spot, rfq.strike, 0.20, rfq.expiry_years, 0.045, 0.015);
            let p = celnet_equity_vanilla::price(rfq.option_type, &inputs);
            (p, (p * 0.005).max(0.01))
        }
        CrossAssetProductKind::Commodity => {
            let inputs = CommodityInputs::on_future(spot, rfq.strike, 0.25, rfq.expiry_years, 0.045);
            let p = celnet_commodity_vanilla::price(rfq.option_type, &inputs);
            (p, (p * 0.005).max(0.01))
        }
        CrossAssetProductKind::DigitalAsset => {
            let inputs = LinearInputs::funded(spot, rfq.strike, 0.60, rfq.expiry_years, 0.045, 0.02);
            let p = celnet_crypto_vanilla::linear::price(rfq.option_type, &inputs);
            (p, (p * 0.01).max(0.05))
        }
    };

    let bid = (fair_price - half_spread).max(0.0);
    let offer = fair_price + half_spread;
    Ok(PricedLine { bid, offer, size: rfq.notional })
}

/// receives a valid two-way Quote(S) with positive bid/offer and tight spread.
#[tokio::test]
async fn fix_cross_asset_equity_rfq_returns_two_way_quote() {
    tokio::time::timeout(DEADLINE, async {
        let clock = Clock::system();
        let (edge, fix_addr) = boot_edge_with_fix(clock).await;

        let mut drv = Driver::connect(fix_addr).await;
        drv.send_app(build_equity_quote_request(b"REQ-EQ-1", b"AAPL", 150.0, 0.5)).await;

        let quote_raw = drv.next_app(MsgType::Quote).await;
        let cursor = FrameCursor::parse(&quote_raw).expect("well-formed Quote");
        let view = QuoteView::new(cursor);

        assert_eq!(view.quote_id().is_some(), true, "carries QuoteID(117)");
        assert_eq!(view.symbol(), Some(b"AAPL".as_slice()), "carries Symbol(55)");
        let bid = view.bid().expect("has valid parsed bid price");
        let offer = view.offer().expect("has valid parsed offer price");
        assert!(bid > 0.0, "bid is positive: {bid}");
        assert!(offer > bid, "offer exceeds bid: {offer} > {bid}");

        edge.shutdown(Duration::from_secs(5)).await;
    })
    .await
    .expect("test timed out");
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PlatformConfig {
    pub consistency: ConsistencyConfig,
    pub gpu: GpuConfig,
    pub plugins: PluginHostConfig,
    pub limits: PlatformLimitsConfig,
    pub sbe_ipc: SbeIpcConfig,
    pub telemetry: PlatformTelemetryConfig,
}

impl PlatformConfig {
    /// Load declarative configuration from path, env, or deterministic defaults.
    pub fn load_or_default(path: Option<&str>) -> Self {
        if let Some(p) = path {
            if let Ok(cfg) = Self::from_file(p) { return cfg; }
        }
        if let Ok(env_path) = std::env::var("CELNET_CONFIG_PATH") {
            if let Ok(cfg) = Self::from_file(&env_path) { return cfg; }
        }
        Self::from_env()
    }
}
