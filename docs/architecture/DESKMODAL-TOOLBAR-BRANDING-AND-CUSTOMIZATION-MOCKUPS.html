1. Enterprise Branding Architecture (`brand-service` cdylib)

DeskModal does not treat branding as an afterthought or a superficial CSS stylesheet. Branding is powered by a dedicated, compiled Rust cdylib service (plugins/brand-service/) running as a REQUIRED system actor inside the Tauri host process. It publishes state across the FDC3 bus via deskmodal.brand.changed and enforces tenant governance.

Single Source of Broadcast Truth
  • Rust cdylib Service: Powered by ArcSwap<ActiveBrandSelection> for lock-free, zero-allocation reads on hot rendering loops.
  • FDC3 Brand Mesh: Broadcasts 7 dedicated channels (changed, installed, preview, os_conformance_changed) to all webviews.
  • Crash-Safe Persistence: Atomic 60s debounced JSON persistence with schema-evolution merge closures.
Enterprise DLP & Lockdown Policy
  • Firm-Enforced Whitelabeling: IT administrators can lock firm branding via brand.locked: true in desk.toml.
  • Ed25519 Signed Bundles: Brand packs are cryptographically signed .dmbrand archives verified before ingestion.
  • Dynamic CSS Injection: Transforms 12 token categories (~120 sub-tokens) into native CSS custom properties at runtime.
12 Brand Token Categories
  • Color Palette: Dark & Light OKLCH color spaces guaranteeing WCAG 2.2 AA/AAA contrast.
  • Typography: Font scale (xs..3xl), monospace tabular numbers for trading screens.
  • Trading Tokens: Up-tick, down-tick, cross, neutral, and FDC3 channel geometric shapes.

2. Multi-OS Native Ergonomics: macOS, Windows 11, and Linux

DeskModal is built with Tauri 2.0 to deliver native desktop integration across all three major operating systems. The toolbar dynamically conforms to host OS conventions rather than forcing a foreign look-and-feel:

Apple macOS (Darwin / Cocoa)
  • Vibrancy & Materials: Utilizes NSVisualEffectView with under-window and behind-window blending modes.
  • Traffic Lights Alignment: In Top Ribbon mode, the bar accounts for window traffic lights with an 80px leading inset.
  • Display Notch Avoidance: Sits flush below the macOS system menu bar without obstructing the camera notch on modern MacBook Pros.
  • System Notifications: NSWorkspaceAccessibilityDisplayOptionsDidChangeNotification integration for real-time reduce-motion and high-contrast response.
Microsoft Windows 11 / 10
  • Mica & Acrylic Materials: Windows 11 Mica / Acrylic backdrop integration via DwmSetWindowAttribute.
  • Taskbar Docking: Automatic edge-snap that respects the Windows Taskbar position (bottom, left, or top) and multi-monitor virtual desktops.
  • Snap Layouts Integration: Interoperates with Windows 11 Snap Groups and Snap Assist without window clipping.
  • High Contrast & forced-colors: Responds to WM_THEMECHANGED and SPI_SETHIGHCONTRAST for WCAG AAA accessibility.
Linux (X11 & Wayland)
  • Wayland Layer-Shell: Native support for wlr-layer-shell-unstable-v1, allowing the toolbar to dock cleanly outside the window tiling grid.
  • Tiling WM Harmony: Zero-disruption companion for i3, Sway, and Hyprland; behaves as an anchored status bar without competing for floating focus.
  • Freedesktop & GTK Sync: GSettings watch on org.gnome.desktop.interface and KDE kdeglobals D-Bus signals for system dark/light switching.

3. App Stacks: Solving the "20-Icon Wall" Scalability Bottleneck

In complex institutional platforms, plugins contribute multiple sovereign sub-apps (e.g. CelNet contributes 6 desks, TradeSurface contributes 8 tools). Flattening these into the toolbar creates an overwhelming wall of icons. We introduce App Stacks in the plugin manifest: 

# Example: plugins/celnet-studio/plugin.toml
[plugin.toolbar]
position = "primary"
group = "celnet.derivatives"
group_title = "CelNet Derivatives"
group_icon = "icons/celnet-suite.svg"
badge_style = "count"     # Renders a subtle "(6)" badge on the stack pill
priority = 10             # Determines horizontal placement order

# Child desks automatically nest inside the CelNet Derivatives Stack
[[apps.entries]]
appId = "celnet.studio.pricing"
name = "Options Pricing Studio"
stack_role = "primary"

[[apps.entries]]
appId = "celnet.studio.markets"
name = "Markets & Streaming Depth"
stack_role = "member"

4. The Modal vs. Tileable Calculus: Eliminating Desktop Obfuscation

DeskModal derives its foundational identity from a critical architectural duality: Windows must be either Modal or Tileable, and the container must NEVER obfuscate valuable desk space. On tier-1 trading desks, screen space is occupied by live market curves, pricing ladders, order feeds, and blotters. A desktop container that hogs space, creates overlapping window clutter ("z-order occlusion hell"), or steals focus is immediately discarded by traders.

Dual Window Modality Matrix
  • Persona A: Ephemeral Modal HUDs: Dedicated to rapid, transient actions (e.g. Quick RFQ Order Tickets, Greeks Sensitivity Sliders, FDC3 Intent Resolvers). They pop instantly under cursor focus, execute via SBE/SHM, and dismiss immediately upon completion or Esc. They do not spawn persistent taskbar entries or disturb the trader's layout.
  • Persona B: Persistent Split-Tree Tiles: Dedicated to analytical and execution desks (e.g. Garman-Kohlhagen Options Pricing, L2 Depth Ladders, Real-Time Blotters). Managed by deskmodal-window-manager::split_tree, windows dock with 0px or 2px gutters in binary BSP trees. Resizing a splitter adjusts adjacent tiles proportionally with zero overlap.
  • Zero Overlap Guarantee: No window ever hides behind another window. Every visible pixel represents active, functional financial telemetry.
Zero Desk Space Obfuscation
  • Razor-Thin Top Strip (34px): Docks flush into the display's dead margins (adjacent to the macOS camera notch, or flush against the Windows taskbar).
  • Proximity Auto-Hide & Edge Reveal: When the trader desires 100% full-screen canvas utilization, the command bar tucks away into an un-obtrusive 3px edge glow strip. Hovering the edge or pressing ⌘K drops the bar smoothly down for instant command routing.
  • OS Work-Area Reservation: DeskModal sets the host OS usable work area via Win32 SPI_SETWORKAREA, macOS Cocoa NSScreen.visibleFrame, and Linux wlr-layer-shell-unstable-v1, ensuring third-party applications snap cleanly around the bar rather than colliding with it.
Native Third-Party Window Adoption (`deskmodal-snap`)
  • Foreign Window Tiling: Institutional traders cannot abandon Bloomberg Terminal, Excel spreadsheets, or Symphony chat. deskmodal-snap::adoption.rs captures native OS window handles (HWND, CGWindowID, X11 IDs) via glob pattern matching.
  • Unified Snap Groups: Third-party windows are adopted directly into DeskModal's split-tree tiling grid, moving, resizing, and minimizing together as a synchronized multi-window workstation.
  • Subclass Intercepts: On Windows, Win32 WM_MOVING and WM_SIZING message hooks ensure adopted Bloomberg/Excel windows track the DeskModal splitters without visual latency or jitter.
