Extensibility Maturity Scorecard

Benchmarking CelNet's current implementation against state-of-the-art 2026 financial architecture.

1. Asset Classes & Products Grade: C+
Closed Sum Types: `Underlying` and `Product` enums in frozen base crate require full rebuild to add inflation, power, or credit hybrids.
SOTA Fix: Dynamic `CashflowStream` and open `ExtensibleInstrument` polymorphic registry.
2. Analytics & Pricing Models Grade: B-
Payload Truncation: `CarryInputs` restricted to single-asset vanilla. 22 of 23 option engines bypass plugins. `wasmi` adds 20x latency tax.
SOTA Fix: Generalized `MultiAssetInputs`, `ExoticPricingModel` trait, and Wasm Component Model JIT.
3. Market Data & Protocols Grade: B
Isolated Codecs: MDP, OUCH, iLink, ETI lack unified session lifecycle. Static FIX tags fail on broker custom ranges.
SOTA Fix: Unified `MarketDataFeedHandler` SPI with dynamic FIX Orchestral schema dictionaries.
4. Risk Cubes & Non-Additive Grade: B+
Rigid Hierarchies: Hardcoded partition keys; lacks dynamic ad-hoc OLAP slicing and non-linear regulatory aggregators (FRTB, SIMM).
SOTA Fix: Arbitrary dimension slicing and pluggable `NonAdditiveRiskAggregator` SPI.
5. Algorithmic Execution & SOR Grade: B-
Hardcoded Strategies: `AlgoStrategyType` is closed enum (TWAP/VWAP/POV). Quants cannot deploy proprietary RL execution tactics.
SOTA Fix: Open `ExecutionStrategy` SPI and dynamic venue fee/rebate scoring graphs.
6. Hardware & Transports Grade: B
Compute Monoculture: WGSL f32 single-asset GBM only. Cannot leverage NVIDIA Tensor Cores or DPDK kernel bypass.
SOTA Fix: Heterogeneous `ComputeBackend` (CUDA PTX, AVX-512) and `TransportDriver` SPI.
7. Enterprise & CDM / FpML Grade: B
Partial Lineage: CDM types exist in `celnet-types`, but no native ISDA FpML parser/serializer and no automated EMIR/CFTC reporting.
SOTA Fix: Bidirectional FpML 5.x XML translator and regulatory transaction reporting event hooks.
8. Client & Developer Surfaces Grade: B-
Missing Python SDK: Zero Python bindings for Jupyter/Polars quant workflows. Monolithic React shell with no FDC3 plugin panels.
SOTA Fix: `celnet-py` PyO3 package with zero-copy PyArrow/Polars, and FDC3 micro-frontend architecture.

Universal Extensibility Evolution Roadmap

Phased, non-disruptive execution plan preserving bit-identical pricing guarantees.

Phase 1: Core Trait Openings & Seam Decoupling Q4 2026

Introduce open trait abstractions alongside legacy enums without breaking backwards compatibility or causing numeric drift.

  • Open Instrument SPI: Implement `DynamicInstrument` and `CashflowLeg` primitives in `celnet-core`.
  • Exotic Plugin Seam: Expand `celnet-plugin-api` with `MultiAssetInputs` and `ExoticPricingModel`.
  • Algo Strategy SPI: Introduce `PluggableExecutionStrategy` in `celnet-algo` with dynamic registry.
Phase 2: Host & Runtime Modernization Q1 2027

Upgrade server routing and sandboxed runtime performance to support sub-microsecond external analytics.

  • Dynamic Server Dispatch: Wire all 23 product arms in `celnet-server` through the installed `ModelRegistry`.
  • Wasm Component Model JIT: Deliver Tier-2 JIT host with fuel metering executing at 95% native speed.
  • Unified Gateway SPI: Standardize MDP 3.0, OUCH, iLink, and ETI under `MarketDataFeedHandler`.
Phase 3: Heterogeneous Compute & Risk Aggregation Q2 2027

Scale risk aggregation to arbitrary ad-hoc dimensions and tap hardware acceleration beyond WGSL.

  • Dynamic OLAP Cube: Decouple `celnet-risk-cube` from static keys, enabling arbitrary tag slicing.
  • Non-Additive Risk SPI: Implement ISDA SIMM v2.6+ and FRTB-SbM curvature aggregators.
  • Compute Backend SPI: Add AVX-512 and NVIDIA CUDA PTX acceleration paths to `celnet-gpu`.
Phase 4: Developer SDKs & Enterprise Interoperability Q3 2027

Provide first-class Python research ergonomics and modular financial desktop integration.

  • Python SDK (`celnet-py`): PyO3 bindings with zero-copy NumPy/PyArrow/Polars memory sharing.
  • ISDA FpML & Reg Lineage: Bidirectional FpML 5.x XML parsing and automated ISO 20022 regulatory reporting.
  • Micro-Frontend GUI: Modular desktop workspace with dynamic widget loading and FDC3 context broadcasting.
